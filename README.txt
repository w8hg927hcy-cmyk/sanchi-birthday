CREATOR / PHOTO-VIDEO MODE:
Open index.html?edit=1 in Chrome. Click through the pages until the Birthday finale (page 6 of 7). The photo and video upload controls appear only there.
- Upload Photo / Upload Video: choose media from your device and preview it.
- Save in this browser: keeps selected media in that browser's IndexedDB.
- Download personalized HTML: creates a personalized HTML file with the selected photo/video embedded. Publish this customized HTML to your static host to make those assets part of the hosted page.

NOTE:
Local browser saves do not synchronize between devices. For direct phone uploads that instantly appear to all visitors on one shared live URL without re-publishing, connect a cloud storage/backend. No arbitrary upload MB cap is set in this prototype; browser, device, and host limits still apply.
